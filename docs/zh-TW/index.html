HistCite Mac

直接在 Mac 上分析 WoS 文獻與引用關係。

匯入 Web of Science 文獻，查看 LCS／GCS，繪製引文編年圖譜，找出文獻集合中的核心論文與研究脈絡。

由 yangnim21029 獨立開發，並非原版 HistCite 的官方 macOS 版本，與原團隊沒有隸屬關係。

下載 Mac 版觀看 60 秒操作示範

免費開源，適用 macOS 13 以上，支援 Apple Silicon 與 Intel。介面為英文，無須 Windows 或 Wine。

感謝 jaywcjlove／小弟调调 收錄專案並分享操作示範。

從文獻集合看見研究脈絡

比較引用指標

LCS 計算文獻在匯入集合內的被引次數；GCS 是 WoS 匯出時記錄的總被引數，不會自動更新。

追蹤研究如何發展

使用 Graph Maker 查看論文之間的引用連結，並開啟單篇文獻，閱讀摘要、參考文獻與書目資料。

資料留在你的 Mac

依作者、期刊或年份分析文獻，儲存工作集合，再匯出表格與圖形。文獻資料在本機處理。

準備 WoS 資料，開始分析

  1. 1

    安裝程式

    下載 Universal DMG，將 HistCite Mac 拖入 Applications。

    Apple Silicon 與 Intel 使用同一份安裝檔。

  2. 2

    匯出文獻

    在 Web of Science 使用以下匯出設定：

    格式
    Plain Text
    內容
    Full Record and Cited References

    請保留原始匯出檔案。

  3. 3

    開啟集合，開始分析

    開啟
    File → Open collection…
    排序依據
    LCS 或 GCS
    繪圖
    Tools → Graph Maker…

也可以先用 12 筆虛構示範資料熟悉操作。

首次在 macOS 啟動

社群版本尚未經 Apple 公證。若 macOS 阻擋開啟，請確認下載來源，再依安裝說明操作。

HistCite Mac 版常見問題

HistCite 有原生 Mac 版嗎？

HistCite Mac 是 yangnim21029 獨立開發的原生 macOS 實作，參照 HistCite 的主要工作流程，無須 Windows、Wine、CrossOver 或虛擬機。它與原版 Windows HistCite、HistCite Pro 是不同專案。

這是原 HistCite 團隊發布的官方版本嗎？

不是。原版 HistCite 的貢獻歸於 Eugene Garfield 與合作團隊；本專案與原團隊沒有隸屬關係，也不包含原版 HistCite 的程式碼或執行檔。

支援哪些資料格式？

可直接開啟 Web of Science 標記式純文字匯出檔、HistCite 集合（.hci）與 HistCite Mac 工作集合（.hcm）。Scopus 原生匯出檔或試算表需先轉為支援的格式。

與原版的相容性如何驗證？

已針對指定資料與操作序列，比較引用指標、分析結果和圖形排版；這不代表所有輸入與功能都已完全等價。請參閱驗證範圍與已知限制。
