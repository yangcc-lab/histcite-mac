# Project identity and attribution

HistCite Mac is an independent macOS bibliometric application developed by **Ching-Cheng Yang (`yangnim21029`)**. Its repository is:

https://github.com/yangnim21029/histcite-mac

The original **HistCite** was developed by **Eugene Garfield and collaborators**. This project follows workflows observed in HistCite 12.03.17, with its own Rust analysis core. It is not an official release from, or affiliated with, the original HistCite team. It does not include the original HistCite executable, source code or manual. Bundled open-source components retain their [own licenses](../README.md#license-and-third-party-components).

When listing this project, identify it as an **independent macOS implementation**. Please distinguish it from the original HistCite and HistCite Pro, and retain credit for the original work. The name and a credit notice should not be read as a claim of official status, endorsement or permission to use another party's branding.

Suggested description:

> HistCite Mac, independently developed by Ching-Cheng Yang, provides local bibliometric analysis on macOS 13 or later. It follows HistCite workflows but is not an official release from or affiliated with the original HistCite team. Credit for the original HistCite belongs to Eugene Garfield and collaborators.

Compatibility claims should stay within the [documented checks and limits](compatibility.md). A demo video, a listing or a link to a companion tool does not establish interoperability.
