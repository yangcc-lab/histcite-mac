# Try a collection

Open `demo-wos.txt` with **File → Open collection…** in HistCite Mac. It contains 12 fictional papers and 31 citation links.

Click **LCS** to find papers cited most often within the collection. Choose **Tools → Graph Maker…** to see the citation timeline. Hover over a node to see its citation, then click to open the paper's details.

All names, records and citation counts in this file are demonstration data. The file is also included in the downloadable DMG.
